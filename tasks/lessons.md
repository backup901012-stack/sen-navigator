## 2026-06-13 [事實準確] CAS/CAC 混淆 + 管理機構錯（官方名詞未逐一查證）

**情境**：評估與分級頁「機制 C」一直寫「衞生署 兒童體能智力測驗服務（CAS）」，
並把各區「測驗中心」都當作 CAS、全部當衞生署管理。老闆指正。

**官方真相（多源查證：HA Content_ID=282515、官方 PDF dkhcac@ha.org.hk、dhcas.gov.hk、data.gov.hk）**：
- 「服務」= Child Assessment **Service**（CAS）；「中心」= Child Assessment **Centre**（CAC）——兩者不同層面，不能混用。
- 全港 **8 間 CAC**：**7 間衞生署**（中九龍／尤德夫人觀塘／尤德夫人沙田／屯門／下葵涌／粉嶺／牛頭角）+ **1 間醫院管理局**營辦（**大口環根德公爵夫人兒童醫院**，港島西聯網，email dkhcac@ha.org.hk、電話 2974 0331）。
- 「大口環」醫院官方是「**根德公爵夫人**兒童醫院」（Duchess of Kent），不是「尤德夫人」；尤德夫人是衞生署觀塘／沙田兩間中心，兩者是不同實體（老闆口述把兩者混了，已用官方名）。

**誤區**：把官方專有名詞（Service vs Centre、縮寫 CAS vs CAC）、管理機構（DH vs HA）當「常識」直接寫，沒有逐一對官方核實。香港 SEN 領域官方名詞精細，差一個字（服務/中心）或一個機構（衞生署/醫管局）就是事實錯誤。

**規則**：本網站任何官方服務／機構／單位名稱、英文縮寫、管理機構、單位數目 →
**必逐一對官方來源查證**（HA / DH / EDB / SWD 官網或 data.gov.hk），不可憑印象。
縮寫要分清「服務（Service）」與「中心／單位（Centre）」層面；列「全部由 X 管理」前必確認有無例外單位。

**升級狀態**：首次（本專案 lessons 首條）。對應 commit 6f64b6e（v1.1.1 → 實為 web v1.9.1）。

## 2026-06-13 [內容/心理輔導] 同理 ≠ 同情（過度同情對 SEN 家庭是壓力）

**情境**：寫公眾教育「認識・同理」頁時，用了「筋疲力盡的家長」「想對每一位說的話」等溫情喊話。
老闆指出：心理輔導中同理（empathy）不同於同情（sympathy）；SEN 家長與孩子對過度同情會有壓力，
覺得是「非同路人旁觀者的說教評論」。

**規則**：寫 SEN／弱勢／照顧者相關文案 →
- 用**同理**（平等、與你同在、不評價、賦能）而非**同情**（由上而下、憐憫、「好慘」、神化、說教）
- 避免：「好可憐」「好偉大／堅強」「不如試吓…」未經邀請的建議、過度溫情、把對象當「不幸」
- 核心：SEN 家庭要的是被當成「平常」對待，不是被同情或讚嘆
- 依據：Brené Brown empathy vs sympathy；同理四要素（換位、不批判、辨識情緒、表達理解）

**升級狀態**：首次。對應 /understanding 頁「同理，不是同情」section（v1.10.0）。

## 2026-06-13 [事實準確] 香港特殊教育官方知識（已查證、可重用）

- **特殊學校非「校網分區派位」**：按殘疾類別/程度/評估建議/家長意願/學額，由 EDB 統一安排；
  入學是經 EDB 專業評估→建議→家長同意→轉介，**不是家長自行報名**。
- **雙軌制**：輕度 SEN→主流學校融合教育（全校參與模式）；較嚴重/多重殘疾→特殊學校。
- **62 所特殊學校**（EDB 2023/24）：智障 43（輕/中/嚴重）、肢障 7、群育 8、視障 2、聽障 1、醫院 1。
- **常見訓練方法**（HKU PAAC）：ABA、DTT、TEACCH、PECS、Floor Time、Social Stories、Sensory Integration；
  早期介入+個別化+家人參與為共識；食療/藥物/輔助療法欠科學證據、勿盲信。
- 對應 /special-schools、/training-methods（v1.11.0）。
